必问清单

按你的三个用途分组

硬筛选 · 答不出就走人

这四问能在开场 10 分钟内筛掉一半。

  1. 聚氨酯泡棉（foam plastics）你们的消防许可和保险允许存吗？合同里排除吗？
  2. 整柜卸柜（devanning）怎么报价——按柜还是按小时？散装手卸 vs 打托卸价差多少？压缩海绵通常是散装手卸，最贵的那种。
  3. 丢货怎么赔，按货值还是按重量？如果答「每磅 $0.50」，一件 30 磅的坐垫赔你 15 美金。当场记下来。
  4. 能出 COI 保险证明吗？Warehouse Legal Liability 保额多少？能不能把我们列为 Additional Insured？

用途一 · FBA 中转 + 贴标换标

  1. 贴 FNSKU 多少钱一件？换外箱多少一箱？打托多少一托？
  2. 能不能帮约 Amazon carrier appointment、建 shipment、贴亚马逊托盘标？
  3. 发 FBA 走 Amazon Partnered Carrier 还是你们自己订 LTL？各自报价怎么算？
  4. 如果因为你们贴错标导致 Amazon 入库缺陷罚款，谁承担？2026 年超大件最高 $8.25/件，5,000 件一次错标 = $41,250。这条必须写进合同。

用途二 · DTC 一件代发

  1. WMS 能 API 对接 Shopify / Walmart / TikTok Shop 吗？分别对接过几家客户？
  2. Pick & pack 首件多少、续件多少？大件附加费从多少磅、多少尺开始算？
  3. 尾程用谁的 UPS/FedEx 账号，折扣几折？能不能用我自己的账号？用他们的账号，你的物流数据和理赔权都不在自己手里，换仓时历史数据也带不走。
  4. 出库时效 SLA 是多少？旺季呢？做不到怎么补偿？

用途三 · 退货处理 / 翻新复卖 ★

这是最难的一环，也是最好的差异化谈判点——13 家里没有一家公开宣传这个能力。

  1. 退货能不能开箱检验 + 分级（可复卖 / 需翻新 / 报废）？出不出检验报告？
  2. 拆封膨胀后的海绵制品，能不能重新真空压缩复装？现在有没有压缩机和封口机？没有的话，愿不愿意为我们上一台？
  3. 复装后的包装能不能过 Amazon 二次入仓标准？
  4. 退货件按什么计费——按件、按小时，还是按耗材另计？
  5. 如果复原不了，堆在仓里的费用怎么算？压缩海绵拆封后体积翻 3–8 倍。这条不事先约定，仓储费会失控。

商务条款 · 最后谈

  1. 仓储费按托还是按立方英尺？压缩海绵是典型泡货——同一托别人放 800 磅五金，你只放 60 磅。按托计费你在替别人的密度买单。争取按重量或按 SKU，或按托但要求高位堆叠。
  2. 一个托盘位怎么定义——过高或超重会不会被重新计成 1.5–2 个货位？不写死定义，前面谈的所有单价都是假的。反过来这也是筹码：你的托只有 300–500 磅，地板负荷远低于常规货，可以拿这点换高度放宽。
  3. 免仓租多少天？第几天起计费？长期仓储附加费怎么涨？淡季三个月不动货怎么算？
  4. 有没有月最低消费 / 最低托盘数 / 开户费 / 押金？押金超 $5,000 或超月费 50% 要警惕。
  5. 签约主体和收款主体是不是同一家？能不能出 W-9？两者不一致是暴雷前最典型的信号。
  6. 如果我要撤仓，提前多久通知？搬出费怎么算？合同里有没有扣货条款（warehouseman's lien）？退出条款比进入条款重要。2003 年修订版 UCC Article 7 允许把 general lien 写进服务合同——这就是搬仓被扣货的法律入口。
  7. 能不能给 2–3 家同品类客户做 reference？要到之后真的打电话过去问。
  8. 旺季 Q4 怎么保障我的货位，能不能写进合同？

Randy / UMax 这条线

  1. 你们接不接同行分包——别家 3PL 把货交给你们落地操作？
  2. 做不做仓中仓 / warehouse-in-warehouse？有没有富余货位可以整块租出去？
  3. 你们的美东配送和拖车，愿不愿意反过来交给我们做？
  4. 如果我们带着中国端货源和头程过来，你们能给什么样的渠道价，跟直客价差多少？

一句话结论：宾州境内基本没有值得跑的华人海外仓——唯一确认的仓盛 Allentown 只做 70 磅以内。真正的战场在新泽西，而且好消息是南泽西那一串（Cherry Hill / Westampton / Burlington / Florence / Bordentown）离你只有 45–70 分钟，比去 Allentown 还近，一天能跑完五家。中泽西 Edison–Somerset 华人集群留给第二天。

最大的单点风险：40 万美金首单全压一家小仓。建议第一柜只放一家试跑 60–90 天，跑顺了再加量，或者一开始就拆两家。前面所有的现场验证都可能被演出来，分散风险不会。
