八个需要确认的问题

前六个对方会问 · 后两个决定我们怎么挑

前六个问题是海外仓在第一次会面就会问、而且答案直接决定他们给什么报价的信息——走访前我们两个人必须口径一致。能给区间就给区间；定不下来的写「待定」并注明什么时候能定，比现场临时编一个数字要好得多。

Q1货量与货型决定报价档位与他们愿不愿意接

把这几项一起写下来就行：
  • 首批到仓时间（给到月份即可）与首批规模（柜数 / 托数）
  • 稳定期月均出库——订单数与件数分开说
  • SKU 数量级、有没有明显的季节性
  • 单件重量与最大外箱尺寸区间（超 50 lbs 或长边超 48 英寸会触发大件附加费，要先说）
  • 到仓形态：散装地板柜还是打托柜（卸柜报价差别很大）

Q2渠道结构与尾程决定他们要投什么作业能力

  • FBA 中转 / DTC 一件代发 / B2B 三者的大致占比，以及一年内的变化方向
  • DTC 涉及哪些平台（决定他们要不要做系统对接、有没有现成接口）
  • 尾程用我们自己的 UPS / FedEx 账号还是他们的
  • 需不需要 LTL 或卡派

Q3头程与清关责任边界，也是最容易扯皮的地方

  • 头程海运谁安排、进口商 / IOR 是谁、清关行是谁
  • 预计到港口岸（决定拖车距离，也决定哪几家在地理上真有优势）
  • 要不要保税或 FTZ——候选里有两家有相关资质，值不值得为这个调整优先级

Q4系统与对账最容易签完约才发现做不到的一块

  • 我们这边用什么系统，需要哪种对接：API 实时 / EDI / 定时表格 / 先手工
  • 透明度的最低要求——建议写死两条：一个能自己随时查的只读账号，一份能到 SKU 级的月度对账单。给不出这两样的，账目基本是黑箱

Q5商务底线谈之前先定，现场不临时让步

  • 期望账期、押金上限、可接受的合同期与锁定期、能接受的最低月消费
  • 结算方式；另外现场要确认签约主体与收款主体是不是同一家、能不能出 W-9

Q6保险与赔付出事之后唯一算数的东西

  • 我们这边货物险的现状，以及对对方责任险保额的要求
  • 赔付按货值还是按重量——行业默认常见的是每磅几毛钱，要不要争取按货值、争取到什么程度
  • 要不要求被列为 Additional Insured / Loss Payee，这是不是签约前置条件

Q7筛选标准与一票否决线决定我们回来怎么排序

走访回来会拿同一张卡给每家打分。请从下面八个维度里挑出你认为最重要的三个，再写下你的一票否决线——否决线比权重更有用，它能让我们在现场当场判断，而不是回来再纠结。
  • 资质与合规（实体、责任险 COI、消防许可、报关 / FMC / FTZ 牌照、DOT 号）
  • 物理能力（面积、装卸门、净高、货架结构、设备、扩容余量）
  • 四项作业能力（转运 / 仓储 / 一件代发 / 退换货，各自的成熟度与实际案例）
  • 系统与透明度（WMS 实机、API 覆盖、只读账号、对账粒度）
  • 商务条件（计价结构、托盘位定义、最低量、押金、锁定期、退出与留置条款）
  • 稳定性与集中度（运营年限、员工规模、客户结构、租约剩余年限、口碑与诉讼）
  • 合作模式意愿（只做终端客户，还是愿意做同行分包、仓中仓、双向业务互换）
  • 地理与尾程（离港距离、离主要 FBA 仓、卡派半径、快递折扣、二日达覆盖）

Q8合作形态与对外口径决定对方派销售还是派老板出来

  • 我们想要的合作形态：纯客户关系、同行分包、仓中仓，还是双向——对方给我们仓配、我们给对方美东以外的业务。形态不同，谈判筹码完全不同
  • 现场统一的自我介绍口径，以及被追问具体品类和货量时怎么回答（首轮邮件已按「一家有较多电商业务的物流公司」发出，未提公司名与品类）
  • 现场谁主谈、后续谁对接
  • 如果你手上还有名单外更值得去的美东仓，或者认为两天走 8–10 家不合理、该砍掉哪几家，一并写在这里

电话预筛

五分钟能筛掉一半
  1. 当前是否在接新客户有些仓货位已被大客户占满，只是没在官网说
  2. 最低月量 / 最低月消费是多少
  3. 整柜卸柜怎么报价按柜还是按小时，散装手卸与打托卸的价差
  4. 能不能出 COI 保险证明电话里就问，含糊其辞的不用去
  5. 签约主体与收款主体是否同一家不一致是行业里最典型的预警信号

现场核验

用眼睛看，不听说法
  1. 喷淋系统等级与消防许可覆盖的商品分类
  2. 装卸门数量、可同时作业数、有无 dock leveler
  3. 净高、货架结构、叉车与地牛数量
  4. 库内现存货物类型全是小件电商货说明没做过我们这一类
  5. 满仓程度与积灰呆货空荡说明没客户，塞满说明旺季会爆
  6. 地面墙角有无水渍、漏雨、虫害痕迹
  7. WMS 现场实机演示不接受截图
  8. 当班人数与员工状态、监控覆盖与录像周期
  9. 有没有称重与量方设备没有 dimensioner，计费口径只能听他们的

要带走的文件

回来才有东西可比
  1. 完整报价单逐项列全，不接受只报仓储和出库两个数字
  2. COI 保险证明看责任险的实际保额数字
  3. 标准服务合同样本重点看退出、留置、涨价三类条款
  4. 脱敏的客户对账单样本看明细有没有到 SKU 级
  5. 公司注册与 W-9
  6. 两到三家客户 reference要到之后真的打电话过去
